Política de Privacidade — RedTeam32

Última atualização: 03 de julho de 2026

O RedTeam32 ("aplicativo", "app") é uma ferramenta de apoio a testes de penetração (pentest) autorizados, que se comunica via USB com um microcontrolador ESP32 e oferece um assistente de inteligência artificial opcional baseado na API do Google Gemini. Esta política explica quais dados o aplicativo trata e como.

1. Quem é o responsável pelo tratamento de dados

Este é um aplicativo desenvolvido e mantido de forma independente. Para dúvidas sobre esta política, entre em contato pelo e-mail informado na seção "Contato" abaixo.

2. Dados que o aplicativo coleta e armazena

Chave de API do Gemini

Ao usar o assistente de IA, você fornece sua própria chave de API do Google Gemini. Essa chave é armazenada apenas localmente no seu dispositivo (usando armazenamento local do sistema operacional) e nunca é enviada para servidores próprios do desenvolvedor. Ela é usada exclusivamente para autenticar suas próprias requisições diretamente à API do Google.

Mensagens do chat e comandos

As mensagens que você digita no assistente de IA, assim como as respostas retornadas pelo dispositivo ESP32 conectado, podem ser enviadas à API do Google Gemini para gerar respostas e sugestões de comando. Essas mensagens não são armazenadas pelo desenvolvedor do aplicativo nem enviadas a qualquer servidor próprio — o app não possui backend.

Comunicação USB/Serial

O aplicativo se conecta a dispositivos USB (ESP32) para enviar e receber comandos seriais. Essa comunicação ocorre inteiramente entre o seu dispositivo móvel e o hardware conectado, de forma local, sem transmissão pela internet.

3. Dados que o aplicativo NÃO coleta

  • Não coletamos nome, e-mail, telefone ou outros dados de identificação pessoal.
  • Não coletamos localização geográfica.
  • Não utilizamos câmera, microfone ou contatos.
  • Não utilizamos cookies, rastreadores ou ferramentas de analytics/publicidade.
  • Não compartilhamos, vendemos ou alugamos dados a terceiros.

4. Serviços de terceiros

O assistente de IA utiliza a API do Google Gemini (Google Generative AI). Ao usar esse recurso, as mensagens enviadas estão sujeitas também à Política de Privacidade do Google e aos Termos de Serviço da API Gemini. O uso do assistente de IA é opcional e requer que o próprio usuário forneça sua chave de API pessoal.

5. Permissões do dispositivo

O aplicativo solicita permissão de acesso a dispositivos USB exclusivamente para estabelecer a comunicação serial com o microcontrolador ESP32. Nenhuma outra permissão sensível é solicitada.

6. Armazenamento e segurança

Os únicos dados persistidos pelo aplicativo (a chave de API do Gemini) ficam salvos localmente no armazenamento privado do próprio dispositivo. Você pode remover esses dados a qualquer momento desinstalando o aplicativo ou limpando seus dados nas configurações do sistema operacional.

7. Uso responsável

Este aplicativo foi desenvolvido para fins educacionais e para uso em testes de penetração autorizados. O usuário é o único responsável por garantir que possui autorização legal para testar qualquer rede ou sistema com o auxílio desta ferramenta.

8. Privacidade infantil

Este aplicativo não é direcionado a crianças e não coleta intencionalmente dados de menores de 13 anos.

9. Alterações nesta política

Esta política pode ser atualizada periodicamente. A data da última atualização está indicada no topo desta página.
